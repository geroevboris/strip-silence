# Clear Silence v0.5.4 — пробная автоматическая нарезка

**Диагностическая версия, не готовая обработка мультитрека.**

На Live 12.4.6 уже подтверждены ручной Cmd+E, Mute и возможность восстановить исходное аудио растягиванием границ. В v0.5.4 проверяется автоматический вызов штатного Split без мыши и без записи обрезанных WAV.

## Проверка на КОПИИ Live Set

1. Установи PKG v0.5.4, запусти Clear Silence для установки Remote Script и полностью перезапусти Ableton.
2. Выбери один WAV-клип без Warp и Loop. Нажми «1. Подготовить тест Split». В Live появится заглушённая дорожка Clear Silence SPLIT TEST.
3. В Arrangement выдели именно временный тестовый клип, не исходный. Вернись в Clear Silence.
4. Нажми «2. Авто Split» и подтверди действие. Приложение установит playhead в нужную долю и отправит в Live Cmd+Shift+Space (переместить insert marker к playhead), затем Cmd+E (разрезать клип).
5. Приложение проверит, что получилось два соседних клипа, разрез стоит точно в рассчитанной доле, обе части ссылаются на прежний полный WAV и другие дорожки не изменились. После проверки будет заглушена только правая часть.
6. В Ableton проверь размьют и растягивание края. Затем нажми «3. Удалить тест». Если автоматический Split не сработал, можно вручную выполнить Cmd+E и нажать «Проверить вручную».

При запросе macOS разреши управление компьютером через Универсальный доступ (Accessibility) для Clear Silence/osascript. Если GUI-команда изменила не тестовую дорожку, НЕ сохраняй копию проекта и проверь Undo.

**Пакетная обработка исходных дорожек намеренно отключена.** Этот выпуск нужен для проверки автоматической точки разреза. Следующим этапом станут множественные разрезы по осциллограмме, затем мультитрек. Цвета/зум/иконка не менялись.
