Clear Silence v0.5.7 — тест нативного автоматического Split на копии Live Set.

По реальному тесту v0.5.6 Cmd+E отправлялась, но временный клип НЕ разрезался, а Live менял выделение в Arrangement. Причина могла быть в том, что Bridge при подготовке автоматического разреза повторно выбирал дорожку и выставлял detail_clip, тем самым сбивая выделение волны. В v0.5.7 перед автоматическим Split эти действия УБРАНЫ: Bridge проверяет, что выбрана только тестовая дорожка, и оставляет фокус и detail_clip неизменными. Если выбран оригинал или другая дорожка — команда не отправляется.

На КОПИИ проекта: установи PKG, запусти Clear Silence для обновления Remote Script, перезапусти Ableton. Подготовь тестовый клип (кнопка 1); в Arrangement кликни ВНУТРИ осциллограммы именно тестового клипа, не по названию и не по заголовку дорожки; вернись в Clear Silence и нажми «Авто Split». Приложение проверит совпадение разреза с целевой долей и поставит Mute только на правую часть. После теста удали тестовую дорожку.

Если всё ещё один клип, автоматизацию не считаем подтверждённой. Изменения чужих дорожек запрещены; тестируй только на копии. Массовая обработка выключена, исходный WAV не изменяется.
