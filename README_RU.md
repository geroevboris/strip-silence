# Clear Silence v0.5.6 — пробная автоматическая нарезка

Исправление по результату v0.5.5 на macOS Monterey 12: System Events может отображать процесс Ableton Live с именем **Live**, даже если пакет программы называется Ableton Live 12 Suite. Ранее скрипт искал только имя, содержащее «Ableton Live», поэтому отказывался работать даже при уже разрешённом Универсальном доступе.

Теперь команда выбирает процесс сначала по bundle ID com.ableton.live, затем по имени Live и только затем по полному названию. Если найдено ноль или более одного экземпляра, команда Split НЕ отправляется, а отображается отдельная ошибка обнаружения процесса — не ошибка разрешений.

**Проверка — только на копии Live Set:** установи PKG, запусти приложение для обновления Remote Script, полностью перезапусти Ableton. Подготовь временный клип, выдели его в Arrangement, нажми «Авто Split», проверь Mute и возможность восстановить аудио. После этого удали тестовую дорожку. Массовая обработка по-прежнему отключена. Исходные WAV не изменяются.

На macOS Monterey разрешения находятся в Системные настройки → Защита и безопасность → Конфиденциальность → Универсальный доступ / Автоматизация.
