# Clear Silence 0.6.1 — штатный Split + Mute в Arrangement

Выбери дорожки, настрой чувствительность по предпросмотру и нажми
**«Разделить и заглушить»**. Приложение выполняет все разрезы последовательно,
а затем заглушает тихие фрагменты. Каждый фрагмент ссылается на исходный WAV:
можно включить его звук и растянуть границы. Аудиофайл не перезаписывается.

## Исправление версии 0.6.0

Раньше проверялся playhead, но перед Cmd+E не активировалось выделение
Arrangement. Теперь перед каждой границей приложение выбирает текущий
фрагмент, фокусирует `Arranger`, выполняет Option+2 и Cmd+Shift+Space,
проверяет доступность Split в меню и повторно проверяет позицию/выбранный
клип. Сам Cmd+E отправляется физическим кодом клавиши, без зависимости от
русской или английской раскладки.

Все получившиеся границы и смещения внутри WAV проверяются с допуском в два
сэмпла. Проверяются также соседние клипы той же дорожки. Mute применяется
только после успешной проверки. Ошибка в интерфейсе больше не дублируется.

## Установка

1. Установи PKG 0.6.1 из Releases.
2. Запусти Clear Silence: приложение обновит ClearSilenceBridge.
3. Полностью закрой и снова запусти Ableton Live.
4. Если требуется: Control Surface → ClearSilenceBridge, MIDI Input/Output → None.
5. Разреши Clear Silence управление в macOS: Универсальный доступ и
   Автоматизация → System Events. После этого выбери дорожки и запусти обработку.

Старый мост 0.6.0 приложение не использует. Рабочий протокол новой версии — 10.

## Статус

Автоматические тесты проверяют в том числе семь клипов на двух дорожках,
последовательность разрезов, смещения WAV, смену темпа, отмену и недоступность
Split. Сборка macOS отдельно компилирует AppleScript и проверяет запуск
упакованного приложения. Это не проверка настоящего Live 12.4.6: в CI его нет.
Надёжность фактического выделения Arrangement ещё должна подтвердиться на Mac.

При остановке выполненные разрезы могут остаться в проекте; их можно отменить
штатным Undo. Новая версия не воссоздаёт клипы через Session и не удаляет
исходники. Обработка поддерживает WAV с выключенными Warp/Loop, без
автоматизации клипа, groove и изменения высоты; темп материала должен быть постоянным.

Подробности работы записываются в `~/Library/Logs/ClearSilence/automation.log`.
