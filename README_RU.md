# Clear Silence v0.5.3 — тест нативного Split

**Это диагностическая версия, а не готовая обработка мультитрека.** Массовый Split + Mute намеренно отключён до проверки поведения реального Ableton Live 12.4.6.

В v0.5.2 испытали управление маркерами: Live оставляет целую длину Arrangement-клипа. Этот путь не используем. Новый тест проверяет штатный Split (Cmd+E), который выполняется внутри Ableton. Оригинальные WAV не изменяются.

## Проверка — на КОПИИ Live Set

1. Закрой Ableton и Clear Silence, установи v0.5.3 PKG.
2. Открой Clear Silence для установки Remote Script, полностью перезапусти Ableton. Убедись, что ClearSilenceBridge выбран как Control Surface.
3. Открой **копию проекта**, выбери в Clear Silence один WAV-клип без Warp и Loop и нажми **«1. Подготовить тест Split»**.
4. В Ableton появится **новая заглушённая дорожка** с именем `Clear Silence SPLIT TEST …`. Открой Arrangement, кликни **внутри единственного тестового клипа** на этой дорожке, а затем нажми **Cmd+E**. Не нажимай Cmd+E на исходной дорожке.
5. Вернись в Clear Silence и нажми **«2. Проверить Split + Mute»**. Программа проверит, что получились ровно два соседних Arrangement-клипа без изменения длительности, оба ссылаются на тот же полный WAV. Если проверка пройдена, заглушит только правый тестовый фрагмент.
6. Проверь в Ableton, что правый фрагмент реально Mute, его можно размьютить и растянуть. Затем нажми **«3. Удалить тест»**. Удаляется только временная дорожка.

**Этот тест пока требует одного ручного Cmd+E**. Следующая разработческая задача — безопасная автоматизация выбора точек и вызова Split через macOS Accessibility, при обязательном контроле реального результата. Не будем генерировать усечённые WAV и выдавать это за обратимую обработку.

Если проверка сообщает о неверной границе — сохрани скриншот отчёта. Если тестовая дорожка была переименована или содержимое изменено, приложение сознательно откажется её автоматически удалять; удали тестовую дорожку в Ableton вручную после проверки.

Старые тесты маркеров и старый Split + Mute не являются рабочими функциями. Операции над исходными дорожками в v0.5.3 заблокированы.

## Требования к готовой версии

- Один регулятор мягче/жёстче с мгновенной осциллограммой
- Настоящий native Split на оригинальной дорожке и `Clip.muted=True` на паузах
- Возможность вручную размьютить клип и восстановить края, используя исходный WAV
- Подтверждение на одном клипе, затем безопасная пакетная обработка
- После этого — зум/панорама, тёплая палитра и правильная иконка macOS
