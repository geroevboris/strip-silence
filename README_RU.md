# Clear Silence v0.2 — замена клипов на исходных дорожках

**Live 12.4.6 / macOS / Python 3**. Независимый инструмент, не связанный с StripSilencer от Antoine Delvig.

В v0.2 добавлены: один интерфейс (`Clear Silence.app`, запасной запуск через `02_START.command`), выбор нескольких дорожек, чувствительность Threshold, минимальная длительность тишины, отступы, предпросмотр количества фрагментов и **замена аудиоклипов прямо на тех же дорожках**. Никаких дополнительных Preview-дорожек по умолчанию нет. Все исходные WAV-файлы остаются нетронутыми.

**Эта сборка протестирована локально на имитации Live API, но пока не испытана в настоящем Ableton.** Сначала запускай на **копии Live Set** с одним-двумя простыми WAV-клипами. Не запускай первую проверку сразу на большом мультитреке.

## Установка / обновление с v0.1.1

1. Закрой прежнее приложение Clear Silence: останови старое окно терминала с `02_START.command`, закрой вкладку интерфейса.
2. Распакуй архив в Downloads. Запусти `01_INSTALL.command` (на macOS при первом запуске может потребоваться правый клик → Открыть). Установщик обновит `ClearSilenceBridge` в `~/Music/Ableton/User Library/Remote Scripts/`. Прежнюю копию перенесёт в `~/Music/Ableton/User Library/.ClearSilence Backups/`, а не оставит вторую Control Surface.
3. **Полностью перезапусти Ableton** и открой **копию проекта**. В `Settings → Link, Tempo & MIDI` выбери `ClearSilenceBridge` для Control Surface; MIDI Input/Output = None.
4. Дважды открой **`Clear Silence.app`**. Приложение открывает свой интерфейс в браузере. Если macOS блокирует неподписанный `.app`, правый клик → Открыть; если и это не помогает, используй **`02_START.command`** (тот же интерфейс). Для обоих вариантов нужен установленный Python 3. Если приложение не открывается, журнал `~/Library/Logs/ClearSilence.log`.

## Использование

1. Останови воспроизведение и запись в Live.
2. В интерфейсе нажми «Обновить», отметь **одну тестовую аудиодорожку**. После успешного теста можно отметить несколько дорожек или «Все».
3. Поставь чувствительность (изначально `-45 dBFS`), минимальную паузу (`150 мс`) и отступ (`30 мс`). Чем выше Threshold (ближе к 0), тем больше тихих звуков может исчезнуть. Программа использует Peak с окном около 10 мс.
4. Нажми **«Найти тишину»**. Анализ ничего не меняет в Live. Прочти количество будущих фрагментов и список пропущенных клипов.
5. **Сохрани копию Live Set.** Нажми **«Заменить оригинальные клипы»** и подтверди. Программа создает фрагменты WAV на диске, удаляет соответствующий длинный клип в Arrangement и размещает отдельные фрагменты **на той же дорожке**. Свойства дорожки, эффекты и маршрутизация не затрагиваются.
6. Прослушай результат, особенно атаки, затухания и границы клипов. После сохранения проекта воспользуйся **File → Collect All and Save**, если переносишь проект на другой компьютер: сгенерированные WAV находятся за пределами проекта.
7. Для закрытия сервера нажми «Закрыть» в интерфейсе.

## Безопасность и ограничения

- Исходные WAV **не перезаписываются и не удаляются**. Отредактированные клипы в Live ссылаются на **новые** WAV в `~/Music/ClearSilence Output/`. Не удаляй эту папку до **Collect All and Save**.
- Прямое редактирование требует `Track.delete_clip`, `Track.create_audio_clip`, `Song.begin_undo_step`, `Song.end_undo_step`, `Song.undo`. Если они недоступны — программа откажется менять проект.
- Один клип заменяется в **одной операции** на основном потоке Live. При ошибке программа вызывает Undo для текущего клипа и **останавливает пакет**; уже успешно заменённые клипы не отменяются автоматически. Пользователь должен проверить результат, а не считать групповой Undo гарантированным для всего проекта.
- Только локальные **WAV PCM / WAV float**, **Warp OFF**, **Loop OFF**, без клиповой автоматизации, Groove, транспонирования или автоматизации темпа. Другие клипы программа **пропускает** и объясняет почему.
- **Клиповые фейды не переносим**, так что если у исходных клипов выставлены ручные фейды, не используйте эту версию для них. Плагины дорожки остаются прежними, но клиповые огибающие и нестандартная временная геометрия пока не поддерживаются.
- Целиком тихие клипы по умолчанию пропускаются. Чтобы удалять их, нужно явно поставить галочку «Удалять целиком абсолютно тихие по порогу клипы».
- Ограничения первого пакетного прототипа: до 120 выбранных дорожек, 150 клипов за один анализ и 150 фрагментов из одного клипа. На больших проектах работай порциями. После правок отдельных клипов не переиспользуй старые результаты анализа.
- При изменении клипа, темпа или положения дорожки после анализа замена будет отклонена. Исходная позиция каждого звука рассчитывается из позиции клипа, смещения в WAV, частоты дискретизации и текущего темпа. До обработки проверяется согласованность длительности.
- Анализ и копирование WAV делаются в отдельном приложении; вызовы Live API направляются в главный поток через очередь Remote Script. Сеть не используется, только `127.0.0.1:47861` (мост) и `127.0.0.1:47862` (интерфейс).
- Если местный браузер уже показывает старую версию, значит, у тебя всё ещё работает v0.1.1 на порту 47862. Закрой старый терминал/приложение и открой v0.2.

## Что проверялось

- Разбиение 16-bit WAV и 32-bit float WAV, корректные границы/байтовые срезы.
- Создание нескольких клипов на **той же** дорожке через имитацию Live API.
- Искусственная ошибка создания клипа: проверка вызова Undo и остановки после ошибки.
- Старый безопасный Preview-режим v0.1.1 сохранён в API (совместимость с прежней программой), но новый интерфейс заточен под замену.
- Синтаксис Python, встроенного JS и структура `.app` проверены. **Запустить реальный Ableton на Mac здесь невозможно** — именно это ещё предстоит проверить.

**Если что-то пойдёт не так:** останови обработку, не сохраняй Live Set поверх оригинала, пришли текст ошибки из браузера и соответствующий участок `Log.txt` Ableton. Исходные аудиофайлы сохранены.
