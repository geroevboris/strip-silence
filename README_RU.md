# Clear Silence v0.3 — собственное окно и визуальный предпросмотр

**macOS · Ableton Live 12.4.6 · Python Remote Script**. Независимая разработка, не связанная с коммерческим StripSilencer.

## Главное исправление

Ошибка `Unknown action` при `0 / 7 клипов` означает, что запрос `replace` не распознал **запущенный в Ableton** Remote Script. В v0.2 не было проверки совместимости моста: старый v0.1.1 мог принимать `status` и `list`, но не знать `replace`. В v0.3 Remote Script сообщает версию и список команд, а приложение проверяет их **до** запуска замены. Пока запущен старый мост, кнопка замены недоступна и появляется инструкция переустановки. Сама ошибка не доказывает, что Ableton повреждён.

## Установка / обновление

1. Сохрани копию Live Set и **полностью закрой Ableton**, а также все окна старого Clear Silence и запущенные `02_START.command`.
2. Распакуй v0.3 в отдельную папку. Запусти `01_INSTALL.command` — он обновит `ClearSilenceBridge` в `~/Music/Ableton/User Library/Remote Scripts/` и сохранит резервную копию предыдущего моста.
3. **Один раз** запусти `03_SETUP_UI.command`. Команда установит `pywebview` и компоненты Cocoa/WebKit в **отдельное виртуальное окружение** `~/Library/Application Support/ClearSilence/ui-venv`, не затрагивая Live или системный Python. Для этого шага нужен интернет и Python 3.10+. На macOS интерфейс использует PyObjC. Если шаг завершился ошибкой, пришли вывод терминала.
4. Открой Ableton. Settings → Link, Tempo & MIDI → Control Surface: `ClearSilenceBridge`, MIDI Input/Output = None.
5. Дважды щёлкни `Clear Silence.app` — откроется **отдельное окно macOS**, а не вкладка браузера. Альтернативный запуск: `02_START.command`. Если окно не открывается — журнал `~/Library/Logs/ClearSilence.log`.
6. В заголовке интерфейса проверь **Bridge 0.3.0**. Если видишь «Старый Remote Script», установка/перезапуск не завершены, поэтому замена заблокирована.

## Использование

1. Останови воспроизведение и запись, открой копию проекта.
2. Отметь дорожку или несколько дорожек слева. Справа выбери отдельный аудиоклип для предпросмотра.
3. Меняй Threshold / Min Silence / Padding. Справа появится **волна с зелёными (сохраняемыми) и красными (удаляемыми) участками**. Расчёт зон использует тот же детектор, что и очистка. Волна обзорная и может не отобразить кратчайшие транзиенты, но интервалы удаления вычисляются по полному анализу.
4. Нажми `Анализ выбранных`, проверь итог, затем `Заменить клипы`. **Сначала на одной тестовой дорожке!**
5. Фрагменты создаются на исходных дорожках. Исходные WAV не изменяются; новые WAV лежат в `~/Music/ClearSilence Output`. Перед переносом проекта используй File → Collect All and Save.

## Ограничения

- Только обычные WAV без Warp/Loop, без автоматизации клипа, Groove и изменения высоты тона.
- Исходные WAV остаются целыми. Меняются клипы в Live, поэтому всегда проверяй на копии проекта.
- Несколько клипов обрабатываются последовательно; Undo — по одному клипу, **не единая гарантированная отмена всего мультитрека**.
- Если на дорожке есть нестандартные фейды, сначала проверяй результат: клиповые фейды не переносятся.
- Версия v0.3 локально проверена с имитацией Live API, а отдельное окно **не проверялось в настоящем macOS/Live из этой среды**.
- Если при обработке произошла ошибка, дальнейшие клипы не затрагиваются, но проверь текущую дорожку перед сохранением. Полностью безопасный откат в реальном Live пока не подтверждён.

## Структура

`app.py` — приложение и HTTP API на localhost; `ui.html` — интерфейс WebKit; `audio.py` — анализ WAV; `ClearSilenceBridge/` — Remote Script; `03_SETUP_UI.command` — приватное окружение с pywebview; `.app` — оболочка отдельного окна; `tests/` — автоматические тесты.
