# Clear Silence — v0.5.2 (безопасная проверка Split + Mute)

**Live 12.4.6 · macOS Apple Silicon · тестовая сборка.**

## Что проверяет v0.5.2

Эта версия **не обрабатывает аудиодорожки и не изменяет исходные клипы**. Она проверяет точно тот API-механизм, который сломался в v0.5.1: можно ли в Live создать короткий аудиорегион из полного WAV и сохранить корректные позиции и длину.

Нажатие **«Проверить нарезку безопасно»**:
1. Выбирает WAV-клип без Warp/Loop из выпадающего списка.
2. На временной **заглушённой** аудиодорожке пробует два механизма: (а) прямое создание Arrangement-клипа с последующей установкой маркеров; (б) Session → Arrangement с установкой маркеров уже после размещения.
3. Считывает реальный `start_time`, `end_time`, `loop_start`, `loop_end` и сравнивает их с ожидаемыми.
4. Удаляет пробные клипы и временную дорожку. Оригинальный клип не затрагивается.
5. Показывает отчёт с фактическим и ожидаемым временем. **Пришли его скриншот или текст.**

Если даже этот тест не подтвердится, никакой Split + Mute не запускается. Массовая кнопка в этой сборке отключена сознательно — это защита от повреждения проекта.

## Установка

1. Закрой Clear Silence и Ableton.
2. Установи PKG v0.5.2 (Apple Silicon).
3. Открой Clear Silence, чтобы обновить Remote Script (при необходимости разреши доступ к папке «Музыка»).
4. Полностью перезапусти Ableton Live и выбери `ClearSilenceBridge` в Control Surface.
5. Для уверенности открой **копию Live Set** с WAV-клипом без Warp/Loop.
6. Выбери клип и нажми «Проверить нарезку безопасно».

### Обязательное требование к окончательной версии

Настоящий **обратимый Split + Mute**: паузы остаются в виде отдельных *заглушённых* клипов, сохраняющих ссылку на весь исходный WAV. Можно включить паузу обратно и растянуть границы. Никакого усечения или перезаписи исходных WAV.

**Сборка не подтверждает, что режим Split + Mute работает в Live**. Она только даёт реальный, безопасный тест. Успех компьютерных моков недостаточен.
