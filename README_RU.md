# Clear Silence v0.6.0 — автоматическая нарезка с Mute (бета)

Теперь в основном окне: **выбери дорожки → настрой одну ручку → «Разделить и заглушить»**. Тестовых дорожек, ручных точек Split и специальных диагностических кнопок больше нет.

Алгоритм:
1. Находит активные и тихие интервалы в исходных WAV выбранных аудиоклипов.
2. Вычисляет ВСЕ границы в долях Arrangement, учитывая позицию клипа и tempo.
3. Последовательно, справа налево, ставит playhead в вычисленные точки, вызывает штатный Split Live (Cmd+Shift+Space / Cmd+E).
4. После КАЖДОГО разреза проверяет, что Live создал дополнительный клип точно в нужном месте. Если нет — прекращает работу, показывает номер разреза и реальную позицию.
5. Только после всех подтверждённых разрезов включает Mute на тихих фрагментах. Исходный WAV не перезаписывается и не режется на отдельные файлы. После обработки можно включать звук и растягивать границы клипов.

Поддерживается режим «Дорожка», «Все», «Выбрать…»; клипы обрабатываются последовательно. Можно нажать «Остановить обработку». Поскольку процесс использует настоящие команды редактирования Live, при ошибке проект может оказаться частично разрезанным; пользователь тестирует на отдельном Live Set.

**Разрешения macOS Monterey 12:** Системные настройки → Защита и безопасность → Конфиденциальность → Универсальный доступ (галочка у Clear Silence); также Автоматизация → System Events при появлении запроса. Никакие Screen Recording или Full Disk Access этому механизму НЕ требуются. Если приложение стороннего разработчика запрашивало дополнительные права, это могло быть связано с его иным способом управления интерфейсом, но копировать такие запросы без необходимости нельзя.

**Статус бета:** автокод и имитационные тесты есть, но точная работа серии Cmd+E на твоём настоящем Ableton Live 12.4.6 ещё должна подтвердиться. В особенности фокус Arrangement после первого разреза и при переключении дорожки. Отчёт о неверной границе — основание для исправления фокуса, а не повторной проверки ручного Split.
