# Clear Silence v0.4.0 — компактное окно

Для **Ableton Live 12.x · macOS Apple Silicon**. Это отдельная утилита с MIDI Remote Script, а не устройство Max for Live. Исправлено отсутствие выбранных дорожек, окно уменьшено до 478 × 740 px, переработана иконка.

1. Закрой Ableton. Установи `Clear_Silence_0.4.0_macOS_Apple_Silicon.pkg`.
2. Найди Clear Silence через Spotlight или в `/Applications/Clear Silence.app`.
3. При первом запуске приложение обновит `ClearSilenceBridge`. **Полностью перезапусти Ableton**, заново выбери `ClearSilenceBridge` в Settings → Link, Tempo & MIDI → Control Surface. MIDI Input/Output = None.
4. Открой копию проекта с WAV-клипом без Warp и Loop. В интерфейсе автоматически выбирается текущая аудиодорожка с клипами; если выбран Master, MIDI или пустая дорожка — режим «Все».
5. При необходимости выбери «Текущая», «Все» или «Выбрать…». Проверь предпросмотр, порог, минимальную паузу и отступы.
6. Нажми «Посчитать» (только анализ), затем «Очистить клипы». Перед изменениями потребуется подтверждение.

**Безопасность:** оригинальные WAV не меняются; фрагменты сохраняются в `~/Music/ClearSilence Output`. Не удаляй эту папку до File → Collect All and Save. Замена проводится для каждого клипа с отдельным Undo; пакетный Undo не гарантирован. Полностью тихие клипы по умолчанию не удаляются. Клип с Warp/Loop, автоматизацией или несовместимой геометрией пропускается.

**Важно:** сборка не протестирована в настоящем Ableton на Mac пользователя. Локальные тесты проверяют алгоритм, мост и выбор дорожек, но не подтверждают работу установленного PKG в твоём окружении. Сначала попробуй один клип на копии Live Set.
