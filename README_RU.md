# Clear Silence v0.5.0 beta — сохраняем звук, заглушаем паузы

**macOS Apple Silicon, Ableton Live 12.4.6. Экспериментальная сборка.**

Новый режим **Split & Mute**: вместо создания обрезанных WAV-файлов приложение пытается создать короткие клипы **со ссылкой на полный исходный WAV**. Звучащие части активны, паузы представлены отдельными **заглушёнными** клипами. Идея — возможность отключить Mute и раскрыть клип по краям после обработки.

> **Важно:** разделение посредством `ClipSlot.create_audio_clip` + `Track.duplicate_clip_to_arrangement` проверено в имитации Live API, но **не проверено в настоящем Ableton на твоём Mac**. Если Live не примет границы, приложение должно вызвать Undo и остановиться. Пробуй только на **копии Live Set с одним простым WAV**, перед любой массовой обработкой вручную проверь раскрытие клипа мышью и отсутствие смещения по таймлайну.

## Интерфейс

Одна ручка **«Мягче — Жёстче»** (0–100%); она одновременно регулирует порог громкости, минимальную длину паузы и защищающий отступ. График строится из одного 10-мс пикового профиля и **обновляется локально мгновенно** при движении ручки. **Ярко-бирюзовое** останется активным, **ярко-розовое** станет заглушёнными клипами. Сам процесс обработки рассчитывает границы заново по исходному WAV перед применением, чтобы избежать расхождения.

В верхней части можно выбрать текущую дорожку, все аудиодорожки либо отметить несколько. Для просмотра доступен список клипов. Одна кнопка **«Разделить и заглушить»** выполняет анализ и после подтверждения вносит изменения.

## Установка

1. Закрой Clear Silence и Ableton Live. Установи `Clear_Silence_0.5.0_macOS_Apple_Silicon.pkg`.
2. Открой Clear Silence из Spotlight или `/Applications`. При первом запуске он обновит `ClearSilenceBridge`; затем **полностью перезапусти Ableton**.
3. `Settings → Link, Tempo & MIDI → Control Surface: ClearSilenceBridge`, MIDI Input и Output — None.
4. **Создай копию Live Set**, выбери одну дорожку с одним WAV (Warp/Loop OFF) и проверь.

## Ограничения и защита

- Только обычные WAV без Warp, Loop, клиповой автоматизации и транспонирования; автоматизация темпа также не поддерживается.
- Должен существовать хотя бы один пустой слот **Session View** на обрабатываемой дорожке — он временно используется и очищается после обработки.
- Во время транзакции оригинальный Arrangement-клип удаляется и создаются несколько сегментов, но каждый сегмент ссылается на **полный исходный файл**, поэтому предполагается возможность развернуть его влево/вправо и вернуть заглушённые части. Это принципиально отличается от старой обрезки с созданием новых WAV-файлов.
- Исходные WAV не редактируются и не перезаписываются.
- По одному Undo-блоку на исходный клип; при ошибке запускается Undo для текущего клипа и дальнейшая обработка прекращается. Полный Undo пакета не гарантирован.
- Клипы с автоматизацией и нестандартным смещением исходного WAV пропускаются.
- API дублирования/границ может отличаться в конкретной установке Live. При первом запуске обязательно проверь, что получившиеся сегменты действительно можно растянуть и unmute. Не используйте на основном рабочем Set, пока проверка не пройдёт.
